## 📝 Описание проекта

Данный сервис спроектирован для обеспечения внутренней коммуникации в рамках корпоративной инфраструктуры. API полностью удовлетворяет жестким требованиям производительности благодаря неблокирующему асинхронному подходу ко всем I/O-операциям.

### Ключевой функционал:
* **Управление профилями:** Авторизация по персональным API-ключам, получение метаданных аккаунта, просмотр чужих профилей.
* **Социальный граф:** Подписка и отписка от сотрудников (Self-Referential Many-to-Many связь).
* **Микроблогинг:** Публикация текстовых твитов с возможностью прикрепления нескольких медиафайлов.
* **Вложения:** Асинхронная загрузка графических файлов (изображений) на сервер.
* **Аналитика:** Система каскадных отметок «Нравится» (лайков) с уникальным составным ограничением в БД.

## 🛠 Используемый стек технологий

* **Backend core:** Python 3.12, FastAPI (ASGI фреймворк)
* **Database & ORM:** PostgreSQL 16, SQLAlchemy 2.0 (Асинхронный маппер asyncpg)
* **File I/O:** aiofiles (Асинхронная работа с диском контейнера)
* **Testing:** Pytest, pytest-asyncio, pytest-cov, SQLite (In-memory среда)
* **Quality Assurance:** Ruff, Flake8 (wemake-python-styleguide), Mypy (Strict mode)
* **DevOps:** Docker, Docker Compose (Multi-stage оптимизированная сборка)

## 🚀 Инструкция по быстрому запуску

Для развертывания проекта на целевом сервере или локальной машине Linux/Windows необходим установленный Docker Daemon.

1. Клонировать репозиторий проекта:
```bash
git clone https://github.com/filkevichilya-beep/twitter_clone.git
cd twitter_clone
```

2. Подготовить файл конфигурации переменных окружения `.env` в корневой папке на основе демонстрационного шаблона:
```bash
cp .env.example .env
```

3. Запустить автоматическую сборку и развертывание контейнеров:
```bash
docker compose up -d --build
```

### Автоматические этапы при старте инфраструктуры:
* Инициализируется контейнер `twitter_db` с базой PostgreSQL.
* Сервис дожидается готовности СУБД с помощью встроенного механизма `healthcheck`.
* Контейнер `twitter_app` запускает скрипт `src/init_db.py`, который накатывает схемы и создает тестовых пользователей (Сергей Брин, Павел Дуров, Элон Маск).
* Запускается веб-сервер Uvicorn на порту `8000` и монтирует готовый интерфейс фронтенда.

## 🧪 Тестирование и контроль качества

Все инструменты качества кода интегрированы в автоматический пайплайн **GitHub Actions**. Проверки выполняются при каждом пуше.

### Локальный запуск инструментов качества:

Автоматическое форматирование кода и сортировка импортов:
```bash
ruff check src/ tests/ --fix
```

Строгая проверка соответствия архитектурным гайдлайнам:
```bash
flake8 src/
```

Проверка статической типизации:
```bash
mypy src/
```

Запуск пакета асинхронных интеграционных тестов с расчетом покрытия:
```bash
pytest --cov=src tests/ --cov-report=term-missing
```
